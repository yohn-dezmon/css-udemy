# HTML

- hypertext markup language
- consists of `elements` (paragraphs, links, headings, images, video, etc.)

```html
<p>HTLM is a markup language</p>
```

- `<p>` - opening tag
- "HTLM is a markup language" -- Content
- `</p>` - closing tag
- the "element" is the opening tag, content, and closing tag

For elements without content, we omit the closing tag. e.g <img>
